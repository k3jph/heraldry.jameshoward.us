# The Heraldry Project

**The language of arms, opened to everyone.**  
A free, independent, interactive school of heraldry at [heraldry.jameshoward.us](https://heraldry.jameshoward.us).

This project combines a structured undergraduate-level introduction to heraldry with an original interactive shield atelier, a searchable lexicon, a teaching armorial, guided practice, and annotated primary institutional sources.

## What is here

- **Academy** — twelve substantial self-paced lessons, reading exercises, knowledge checks, and locally saved progress.
- **Atelier** — vector shield composition, live introductory blazons, downloadable SVG artwork, sharable URLs, and advisory tincture checks.
- **Armorial** — original, clearly labeled teaching designs for comparing charges, divisions, and ordinaries; not a register of granted arms.
- **Lexicon** — searchable reference vocabulary, with a fast learning tool for terms used across traditions.
- **Field guide** — heraldic anatomy and a clear treatment of jurisdiction, authority, inheritance, and good research.
- **Sources** — official heraldic authorities, peer education organizations, and selected archival gateways.

## Editorial commitments

1. **Accuracy before folklore.** Arms are not automatically owned by everyone with a surname. A crest is not the shield or complete achievement. Laws vary by jurisdiction.
2. **Show, don't just tell.** Wherever possible, a concept should be demonstrated as something the reader can manipulate.
3. **Original educational artwork.** Pedagogical examples are designed for this project and are not portrayed as registered grants.
4. **Progress without surveillance.** Exercises and learning progress are stored in the visitor's browser only.
5. **Accessibility.** Keyboard navigation, semantic HTML, contrast, focus treatment, and reduced-motion support are first-class requirements.
6. **Scholarly humility.** Heraldic conventions are taught as traditions, not as universally binding legal rules; cite primary institutional guidance where possible.

## Technology

Astro (static generation), TypeScript, original SVG illustrations, progressive enhancement and a small amount of browser-native JavaScript. No accounts, no server, no proprietary widget infrastructure.

```sh
npm install
npm run dev
npm run check
npm run build
npm run preview
```

Build output is `dist/`; `netlify.toml` provides an optional deploy configuration.

## Status and scope

An actively developed independent educational project. The course does not grant academic credit or confer authority to bear arms. No blazon or design supplied by its tools is a legal grant of arms.
